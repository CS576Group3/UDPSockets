# Programming Assignment #2

Keyword: UDP Socket, Client – Server

You are to write a UDP connectionless client-server pair in the language of your choice. The client will send a UDP message to the server, e.g. “Hello”. The server will start and run on a port number at your choice and return the original message concatenated with a humorous message as an ASCII string to the client on a port at your choice. The client will then present a formatted string to the monitor.

As an example, the basic output should look like:

Your client program sends “Hello”
Your client program would receive the string “Hello – [Replace with your humorous message]” from the server.

Please feel free to choose any programming language, on any operating system.

Please copy/paste the screen shot pictures of your program, and attach source code to the end of your report. Due to extreme diversity of platforms, it is impossible to validate each individual implementation by running each program on one computer. Thus, submitting the report in PDF is anticipated on canvas on the due date.

Please work in your project group and let the team leader submit 1 high quality programming report as a group.
